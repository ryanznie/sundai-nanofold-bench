Metrics Guide

Metrics Glossary

Definitions and expected ranges for structure quality metrics.

Metric Range Description
FoldScore 0.0 → 1.0 Composite ranking metric: 0.5 × GDT-HA + 0.3 × lDDT-atom14 + 0.2 × MolProbity. Higher is better. This is the primary leaderboard metric.
GDT-HA 0.0 → 1.0 Global Distance Test High Accuracy. Measures the fraction of C-alpha atoms superimposed within 0.5Å, 1Å, 2Å, and 4Å of the reference. The CASP gold-standard for global fold quality. Weight: 0.5.
lDDT-atom14 0.0 → 1.0 Local Distance Difference Test computed over all heavy atoms (atom14 representation). Measures preservation of local inter-atomic distances within a 15Å neighbourhood. AlphaFold’s primary confidence metric. Weight: 0.3.
MolProbity Clash 0.0 → 1.0 Physical clash score derived from MolProbity. Penalises steric clashes between non-bonded atoms. 1.0 means no clashes; lower values indicate physically implausible structures. Weight: 0.2.
GDT-TS (diagnostic) 0.0 → 1.0 Global Distance Test Total Score. Thresholds 1Å, 2Å, 4Å, 8Å on C-alpha atoms. Reported for reference but not included in FoldScore.
lDDT-CA (diagnostic) 0.0 → 1.0 lDDT computed on C-alpha atoms only. Faster to compute than lDDT-atom14; reported for monitoring but not included in FoldScore.
Runtime Seconds Total wall-clock time for inference across all targets in the benchmark bundle. Not part of FoldScore; shown for efficiency comparison.
